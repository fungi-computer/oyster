# Oyster host illustrations

The three approved November 5 Oyster illustrations: desktop repair, owner key
and reconnect. These host-specific traces and transparent light/dark AVIF plates
are the qualified outputs from the existing landing art workflow. Sprite already
owns the runtime ink renderer and is an Oyster dependency; no tracing tools or
native image libraries are copied into Oyster.

`provenance.json` records the reviewed output hashes before formatting. The
original manga sources, prompts and overlays remain in the November 5 art
review. The build embeds only these nine small outputs, with content-addressed
URLs. Images remain decorative; every form and recovery action is server
rendered.
